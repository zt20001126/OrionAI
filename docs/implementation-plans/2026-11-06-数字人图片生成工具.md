# 数字人图片生成工具实现方案

> 日期：2026-11-06
> 状态：待审阅

## 目标与范围

数字人根据用户的文字描述生成一张图片，使用阿里云百炼 `qwen-image-2.1-turbo`，成功后保存至现有私有 OSS，并在当前对话和历史消息中展示缩略图。生成时保留数字人的文字、语音及停止交互。用户未指定尺寸时不弹画幅题卡；请求不传 size，模型按默认行为生成。用户要求横版、竖版或其他构图时将要求保留在提示词中。

参照图片智能体的任务状态、下载校验、OSS 保存和消息结果语义，数字人独立接入百炼。原图片智能体及其前端页面、TokenHub 下载器和调用链均不修改，不移植其商品限定、腾讯参数或画幅题卡。本期仅文生图、单图，不包含参考图、图片编辑、翻译、独立缩略图文件或新导航。

## 现有实现与依据

- `backend/app/modules/agents/image_agent/tools/generate_image.py`：创建任务、调用 TokenHub、下载、上传及更新状态；当前写死图片助手技能标识和 TokenHub 参数。
- `backend/app/modules/image_generation/providers/result_downloader.py`：只允许腾讯域名，且错误类型绑定 TokenHub；不能原样用于百炼。
- `backend/app/modules/image_generation/service.py`、`models.py`、`router.py`：已有任务结果、用户归属校验及私有图片读取。
- `backend/app/modules/digital_human/agent/graph.py`、`runtime.py`、`state.py`：数字人图注册工具，运行结果目前为文本或题卡；`AgentResponse` 已有 `image_result_id`。
- `backend/app/modules/conversations/service/service.py`：已将图片 ID 保存为 `image_result` 消息部分；数字人请求结束后前端刷新持久化消息。
- `frontend/src/features/conversations/ConversationPage.tsx`：已有图片缩略显示和查看原图；数字人组件尚未渲染该内容。
- 百炼 [Qwen 图像 API](https://help.aliyun.com/zh/model-studio/qwen-image-generation-and-editing-api-reference) 支持该模型、可选 size 和自动推荐尺寸；结果 URL 为临时地址，需及时保存。模型、密钥和 endpoint 必须同地域。

## 设计与流程

```text
数字人文字请求 → 识别生图意图 → 生图工具（可信运行上下文）
→ 创建 running 任务 → 百炼生成 → 受限下载 → 私有 OSS → succeeded
→ 当前轮结果 ID → AgentResponse → 保存文本和 image_result → 刷新消息 → 缩略图
```

1. 使用现有百炼密钥与地址，图片模型独立配置；固定请求与下载超时放在数字人代码常量中。配置缺失、权限不足、超时、配额和返回异常均产生清晰失败，日志不包含密钥、完整提示词及临时签名 URL。
2. 新增百炼 Provider，按官方兼容接口请求 `images/generations`，`n=1`，不传 size，解析 `data[0].url`。同步等待该 HTTP 请求时维持现有 SSE 心跳；地区和模型可用性上线前通过真实环境验证。
3. 数字人独立编排任务状态、图片下载和私有 OSS 保存，直接使用现有 TaskResultStore 和 OSS 基础设施，不改造原图片助手工具或共享 service。百炼专用下载器直接读取返回的地址，保留禁止重定向、MIME、文件签名和大小校验。PNG/JPEG 按实际类型存储。
4. 数字人注册模块级 `generate_image` 工具，模型只提供提示词；user_id 和 conversation_id 从服务端运行上下文读取，任务 ID 在服务端生成。工具调用失败时记录失败并返回可理解的错误，不声称成功。Runtime 只从最新用户消息之后的生图工具结果提取任务 ID，映射到 AgentResponse，避免历史消息被重复附图或模型文本伪造 ID。
5. 在数字人模块新增图片展示组件，遵循现有图片助手的展示和交互方式，使用同一私有地址，支持失败提示、键盘访问及查看原图；不修改或抽取原图片助手页面的组件。缩略展示使用原图的 CSS 限制尺寸，浏览器仍下载原图。
6. 文本和语音沿用现有 SSE；图片随本轮结果持久化，流结束后数字人页面通过现有刷新展示，不增加图片 SSE 事件。工具的任务记录、对象键和私有读取复用图片结果基础设施；不增加后台重试或独立任务调度。

## 接口与数据影响

| 接口 | 操作 | 契约和兼容性 |
|---|---|---|
| `POST /api/conversations/{conversation_id}/messages/stream?voice=true` | 不变 | 保留现有文本、语音与结束事件；生成完成后消息可包含已有 `image_result`。 |
| `POST /api/conversations/{conversation_id}/answers/stream?voice=true` | 不变 | 现有题卡恢复行为不变；若恢复后生图，同样保存图片消息。 |
| `POST /api/conversations/{conversation_id}/messages`、`POST /api/conversations/{conversation_id}/answers` | 不变 | 现有消息结果结构已支持 `image_result`。 |
| `GET /api/conversations/{conversation_id}/messages` | 不变 | 通过已有消息 parts 返回图片结果。 |
| `GET /api/v1/task-results/{task_result_id}/image` | 不变 | 复用所属用户校验及私有 OSS 读取。 |
| 百炼 `POST .../compatible-mode/v1/images/generations` | 新接入的外部调用 | 请求模型和提示词，解析临时图片地址；遵循百炼地域和认证要求。 |

数据库无结构变更、迁移或回填：复用 `task_results.id/user_id/conversation_id/skill_code/result/created_at`，使用 `digital_human` 技能归属、现有 result JSON 状态及对象键；复用 `messages.content` 保存已有 `image_result`，`conversations` 归属关系不变。上述字段以 `backend/app/modules/image_generation/models.py` 和 `backend/app/modules/conversations/models/models.py` 为准。图片保存在现有私有 OSS，不新增表、字段或公开 URL。

## 分步实施与验收

1. **百炼 Provider 与下载**：修改配置，新增百炼客户端和独立下载器；原 TokenHub 下载器不改。验收：请求省略 size；错误响应、非法图片及超时均失败。通过 mock HTTP 单元测试验证。
2. **数字人任务与 OSS 保存**：在数字人工具中调用现有任务仓储及 OSS 基础设施，独立编排保存过程；不修改原生图工具和图片生成 service。验收：成功任务从 running 转为 succeeded 并可读取图片；调用、下载、上传失败不产生成功图片消息；原图片助手行为及测试保持通过。
3. **数字人工具与结果链路**：注册工具并在 Runtime 映射当前轮结果 ID。验收：自然语言生图不触发画幅题卡；完成后返回当前轮图片 ID；普通聊天不附带旧图；不同用户不可交叉读取。
4. **前端展示**：在数字人模块新增图片展示组件并渲染消息，不修改原图片助手页面。验收：流结束后同一消息显示文字和缩略图，可查看原图；刷新或重新进入仍可见；图片读取失败有提示；不破坏原图片助手页面和数字人的语音、题卡、停止交互。
5. **联调与回归**：在已配置百炼和 OSS 的环境执行一次真实生图并验证私有读取；运行 `backend/tests/unit/test_image_agent.py`、`test_digital_human_agent.py`、`test_digital_human_speech_stream.py`、`backend/tests/integration/test_image_result_endpoint.py` 及相关新增测试，运行前端相关测试和类型检查。测试须覆盖用户隔离、重复提交、取消、工具错误和历史恢复。实际结果在实施后记录，当前未运行测试。

## 风险与运行考虑

- 当前工作区的百炼账户是否开通模型、真实结果域名和超时特性未验证，联调前不可假定可用。
- 用户取消会等待已启动的数据库或 OSS 同步操作结束，将任务标记失败并清理未完成图片；百炼已接受的请求仍可能计费。若图片成功保存后会话消息落库失败，可能留下无消息引用的成功任务和 OSS 图片，本期不新增清理任务。工具不会自动重试付费请求。
- 缩略图使用原图，流量与原图相同；后续有明确性能需求再增加独立缩略图。
- 原图片智能体代码、TokenHub 下载器和图片助手页面均不修改；回滚数字人新增能力时，现有任务和图片记录保持可读。
